Urutan di sini menentukan urutan tampil kategori di aplikasi (field category_order). Centang "sembunyikan" untuk menonaktifkan kategori tanpa menghapus channel-nya.

Semua field channel bisa diedit langsung. Field kosong tidak akan disimpan ke JSON.

Menu mengelompokkan beberapa kategori ke dalam satu dropdown (mis. menu "SPORT" berisi sub-kategori SPORT, BEIN SPORT). Nama sub-kategori harus persis sama dengan nama kategori channel.

Isi "Path file config/features.json" di layar hubungkan, lalu Muat ulang, supaya tab ini aktif.

Dua link ini tertanam permanen di aplikasi (strings.xml) sebagai bawaan. Isi field di bawah untuk MENGGANTI link itu tanpa build ulang APK — aplikasi akan memakai link di sini duluan, dan baru jatuh balik ke bawaan di strings.xml kalau field ini dikosongkan.

Sumber playlist tambahan

Tambahkan link playlist baru (seperti link Vision+ dulu) tanpa perlu build ulang APK sama sekali. Begitu disimpan, link ini otomatis aktif di SEMUA perangkat.

Urutan kategori global (semua sumber)

Ini yang menentukan posisi akhir kategori setelah SEMUA sumber playlist digabung — termasuk kategori dari link M3U seperti "V+ IONTV" atau "Dunia Wibu" yang tidak ada di channels.json. Ketik nama kategori persis seperti yang muncul di aplikasi.

Perubahan di tab ini disimpan ke file config/features.json, terpisah dari channels.json. Field lain di file itu (pengaturan fitur, tema, dll.) tidak ikut berubah.

Mode mentah untuk edit langsung / tempel JSON lengkap. Tekan "Terapkan ke form" untuk menyinkronkan ke tab lain, atau edit di tab lain lalu buka tab ini untuk melihat hasilnya.

Simpan perubahan
Commit langsung ke repo. channels.json dan config/features.json (kalau dimuat) disimpan sebagai dua commit terpisah.
Catatan: alat ini hanya mengedit isi channels.json (dan file sejenis yang di-load lewat link). URL sumber yang ditanam di strings.xml aplikasi (baked-in default source) tidak bisa diubah dari sini — itu perlu edit kode & build ulang APK. Tapi kalau URL itu sendiri menunjuk ke file JSON di GitHub, isi filenya tetap bisa diatur penuh lewat alat ini.
